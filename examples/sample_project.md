# 示例项目：霓虹回声

这个示例展示 NovelWriter Agent 生成物的形态。你可以直接运行：

```powershell
python main.py list
python main.py select sample-cyber-mystery
python main.py check 1
python main.py export
```

示例项目目录：

```text
novels/sample-cyber-mystery/
  metadata.json
  memory.json
  characters.json
  worldbuilding.md
  outline.md
  chapters/chapter_001.md
  chapters/chapter_002.md
  exported_novel.md
```

核心设定：

- 类型：赛博朋克悬疑
- 主角：失去部分记忆的城市调查员林澈
- 世界观：巨型城市被算法和财阀共同统治，记忆可被交易
- 风格：网文节奏，悬疑推进，画面感强

你也可以在 mock 模式下创建新项目并生成完整流程。
